# Princessmel Boutique

Landing/e-commerce conceitual premium para uma microempresa de moda com direção editorial, atmosfera delicada e leitura comercial clara.

## Visão geral

Princessmel Boutique foi desenhada como uma boutique moderna com propósito, sem cair em visual gospel genérico. O projeto combina moda feminina, masculina, vestidos modestos, beleza, Bíblias e acessórios em uma interface que valoriza produto, narrativa e conversão por contato.

## Objetivo do projeto

- Elevar a percepção visual de uma microempresa local.
- Traduzir fé cristã com sofisticação e clareza.
- Criar uma base escalável para catálogo, campanhas e fluxo comercial.
- Construir uma landing pronta para virar case de apresentação.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide Icons
- Componentes próprios inspirados em shadcn/ui

## Features

- Header com navegação, logo customizada e menu mobile refinado
- Hero editorial com composição assimétrica e CTAs claros
- Categorias com grid premium e hierarquia forte
- Seção de coleção com mock data centralizado
- Cards de produto com placeholders elegantes para fotos futuras
- Seção de propósito alinhando fé, modéstia e posicionamento premium
- Galeria editorial com estrutura para campanhas reais
- Bloco de experiência com diferenciais comerciais
- Área de contato com foco em WhatsApp e Instagram
- Footer institucional com assinatura de marca

## Identidade visual

- Paleta: off-white quente, creme, champagne, dourado queimado, grafite suave e preto elegante
- Tipografia: serif editorial para headlines e sans limpa para interface
- Linguagem: boutique contemporânea, delicada, limpa e comercializável
- Logo: coroa minimalista de 5 pontas conectadas ao corpo da coroa
